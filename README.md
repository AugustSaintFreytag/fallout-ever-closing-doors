# Saint's Ever-Closing Doors

A mod for Fallout: New Vegas / Tale of Two Wastelands that adds auto-closing logic for all doors in the game. All doors left open by NPCs and the player will be auto-closed after a set time delay since it was opened and if the player is far away enough. A lightweight remedy to careening through crowded and cramped Rivet City and be blockaded by every single private room door being wide open after city dwellers have commenced their morning routine. Written in NVSE, ESPLess, safe to add and remove at any time.

The mod can be configured in the included INI file. Use the keyword file to blacklist doors that should not be closed.
